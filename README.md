# 🎲 B站收藏夹抽签 (Bilibili Fav Random Picker)

>  B 站收藏夹随机抽取工具 ——在任意 B 站页面从指定收藏夹中一键随机抽取视频。

## ✨ 特性

- 🖱️ **电脑端**：书签栏一键抽取
- 📱 **手机端**：浏览器用户脚本悬浮按钮
- 🔒 **支持私密收藏夹**（浏览器需登陆b站账号）：请求天然携带 B 站登录态；脚本不读取、不上传你的任何 Cookie
- 📋 **结果可直接打开**：弹窗显示序号 / 标题 / UP主 / BV号 / 链接，确认后直接打开视频
- 💀 **自动跳过失效视频**：抽中失效条目自动重试（最多 10 次）

## 🖥️ 电脑端安装与使用（书签脚本）

1. 下载本仓库的 `index.html` 并双击在浏览器中打开；

2. 将脚本添加到浏览器书签（a. 按 `Ctrl+Shift+B` 显示书签栏，把页面上的「🎲 B站收藏夹抽签」按钮拖到书签栏；b.也可点页面上的"复制代码"，在书签管理器中手动新建书签并粘贴到网址栏）

3. a. 在浏览器中打开你要抽取的b站收藏夹页面，在书签栏中打开本工具 → 弹窗显示抽中的视频 → 点「确定」可将抽中的视频在新标签页中打开。

   b.（不推荐，仅限公开收藏夹）也可以在任意b站页面打开本工具书签，手动输入 fid 抽取公开收藏夹。



## 📱 手机端安装与使用（用户脚本）

​任何支持用户脚本（如油猴）扩展的浏览器均可。在浏览器中导入 `bilibili-fav-rand.user.js` 脚本（文本复制粘贴即可）后，用**浏览器**打开b站页面，右下角会出现悬浮 🎲 按钮。第一次点击🎲按钮会提示输入fid（要抽取的b站收藏夹id），此后将记住该收藏夹；如需修改要抽取的收藏夹，请长按🎲按钮。

**iOS（Safari）安装步骤**：Safari 没有内置脚本功能，需借助免费的扩展 App，二选一：

1. **Stay**（对国内用户友好）：App Store 安装 Stay → 按首次引导进入「设置 App → Safari → 扩展 → Stay」打开允许，并将「所有网站」设为允许 → 复制本脚本全文 → Stay App → 脚本 → ＋ 新建 → 粘贴保存；
2. **Userscripts**（开源）：App Store 安装 → 首次打开指定脚本目录（推荐 iCloud Drive）→ 把 `bilibili-fav-rand.user.js` 文件放进该目录（AirDrop / “文件”App 均可），无需复制粘贴；

然后在「设置 → Safari → 扩展」中确认对应扩展已允许，Safari 打开任意 B 站页面（手机版 m.bilibili.com 也可以），在地址栏左侧的 ᴀᴀ/扩展菜单中启用，右下角出现 🎲 按钮，用法与安卓相同。脚本带着 Safari 的 B 站登录态，**私密收藏夹同样可抽**。

## ❓ 常见问题

**会泄露我的账号吗？**
不会。脚本只在你点击时向 B 站官方接口发起读取请求，不采集、不上传任何数据，也没有任何外部依赖。私密收藏夹能用，仅仅因为请求发生在你自己的登录会话里。

**抽到失效视频怎么办？**
会自动跳过并重试（最多 10 次）；若收藏夹里失效比例过高，才会提示稍后再试。
