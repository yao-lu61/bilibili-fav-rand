# 🎲 B站收藏夹抽签 (Bilibili Fav Random Picker)

> 零部署的 B 站收藏夹随机抽取工具 —— 一条书签 / 一个用户脚本，在任意 B 站页面一键随机抽取收藏夹里的视频。

B 站没有"从收藏夹随机抽一个视频"的功能。本工具把几十行脚本放进 B 站自己的页面里运行，请求与 B 站自家网页完全相同，因此**不受跨域与风控限制**：无需服务端、无需部署、无需配置登录凭证，并天然支持**私密收藏夹**。

## ✨ 特性

- 🚫 **零部署**：纯前端，无服务端、无构建、无依赖
- 🖱️ **电脑**：书签栏一键抽取（Bookmarklet）
- 📱 **手机**：用户脚本悬浮按钮，支持手机版 Edge（Tampermonkey）、Via、X 浏览器、iOS Safari（Stay / Userscripts）等
- 🔒 **支持私密收藏夹**：请求天然携带 B 站登录态；脚本不读取、不上传你的任何 Cookie
- 💀 **自动跳过失效视频**：抽中失效条目自动重试（最多 10 次）
- 📋 **结果可复制**：弹窗显示序号 / 标题 / UP主 / BV号 / 链接，确认后直接打开视频

## 🖥️ 电脑端安装（书签脚本）

1. 下载本仓库的 `docs/index.html` 并双击打开（若本仓库已开启 GitHub Pages，直接访问在线安装页即可）；
2. 按 `Ctrl+Shift+B` 显示书签栏，把页面上的「🎲 B站收藏夹抽签」按钮**拖到书签栏**；
   （也可点页面上的"复制代码"，在书签管理器中手动新建书签并粘贴到网址栏）
3. 在 B 站打开你的收藏夹页面，点书签 → 弹窗显示抽中的视频 → 点「确定」新标签打开。

也可以在任意 bilibili 页面点书签，手动输入 fid 抽其他公开收藏夹。

## 📱 手机端安装（用户脚本）

任何支持用户脚本的浏览器均可，导入 `bili-random.user.js` 后，打开收藏夹页面，右下角会出现悬浮 🎲 按钮：

| 平台 | 方式 |
|---|---|
| 安卓 · 手机版 Edge | 菜单 → 扩展 → 安装 **Tampermonkey** → 扩展面板底部「+」新建脚本 → 粘贴脚本全部内容并保存 |
| 安卓 · 轻量浏览器 | 「Via」「X 浏览器」自带用户脚本功能（设置 → 通用 → 用户脚本 → ➕ 粘贴） |
| 安卓 · 其他 | 「Kiwi」「Firefox」先装 Tampermonkey 扩展再导入 |
| iOS · Safari | App Store 安装「Userscripts」「Stay」或「Tampermonkey」，按其引导导入并启用 |

脚本内容传到手机：将 `bili-random.user.js` 通过微信/QQ 发送给自己，复制全文粘贴即可。

## 🎮 使用

- 打开任意 bilibili 页面（手机版 m.bilibili.com 也可以）；
- 电脑：点书签；手机：点右下角悬浮 🎲 按钮；
- **首次使用**会要求输入一次 fid（收藏夹链接 `fid=` 后面的数字），之后**永久记住**，任何页面直接抽取；
- 弹窗显示 `#序号 标题 / UP主 / BV号`，点「确定」打开视频；
- **长按**（手机）/ **右键**（电脑）按钮可更换要抽取的收藏夹。

## ❓ 常见问题

**为什么它不需要部署？**
脚本直接运行在 bilibili.com 页面内，发出的请求和 B 站自家网页完全相同（同站请求），跨域与风控都不存在。这也是它只能在 bilibili.com 页面上使用的原因。

**会泄露我的账号吗？**
不会。脚本只在你点击时向 B 站官方接口发起读取请求，不采集、不上传任何数据，也没有任何外部依赖。私密收藏夹能用，仅仅因为请求发生在你自己的登录会话里。

**抽到失效视频怎么办？**
会自动跳过并重试（最多 10 次）；若收藏夹里失效比例过高，才会提示稍后再试。

**为什么没有"不重复抽取"记录？**
书签 / 用户脚本刻意保持极简、无持久化状态。如果你需要抽取记录、跨收藏夹混合等功能，可以基于本项目的思路自行扩展。

**点书签没反应？**
确认当前页面是 bilibili.com 的页面；确认书签网址以 `javascript:` 开头且完整（手动创建时该前缀必须手动键入，粘贴会被浏览器吞掉）。
