🎲 B站收藏夹抽签 · 书签脚本安装

装一次，之后在 B 站收藏夹页面点一下书签即可随机抽取，弹窗显示 BV 号，确认后直接打开视频。无需任何服务、无需部署。

安装（二选一）

方式一（推荐）：拖拽 —— 显示书签栏（Ctrl+Shift+B），然后把下面这个按钮按住拖到书签栏松手：

🎲 B站收藏夹抽签（把我拖到书签栏）

方式二：手动粘贴 —— 复制下面全部代码 → Chrome 菜单 → 书签 → 书签管理器 → 右上角 ⋮ → 「添加新书签」→ 名称随意、网址粘贴代码 → 保存。

使用

  1. 在 B 站打开你的收藏夹页面（地址栏带 fid=xxx），点书签栏的「🎲 B站收藏夹抽签」；
  2. 弹窗显示抽中的视频（序号/标题/BV号/UP主），点「确定」新标签打开视频；
  3. 也可以在任意 bilibili 页面点书签，手动输入 fid 抽任意公开收藏夹。
  • 脚本跑在 B 站页面里、带着你的登录态，公开 / 私密收藏夹都能抽；失效视频自动跳过。
  • 只在 bilibili.com 页面上有效（这正是它能绕开风控的原因）。
  • 每次抽取 1~2 个请求，正常使用不会触发风控。
